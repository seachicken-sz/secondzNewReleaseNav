# secondzNewReleaseNav

timeleszの新曲応援方法を案内する、非公式・静的Webアプリです。

## 使い方

GitHub Pagesの公開元を `main` のルート（`/ (root)`）に設定すると、`https://seachicken-sz.github.io/secondzNewReleaseNav/` で公開できます。リポジトリがprivateのため、プラン・公開設定によってPagesを有効化できない場合があります。

## ファイル

- `index.html`, `style.css`: 画面
- `js/app.js`: 質問表示、スナップ式予算スライダー、途中保存、結果表示、PNG出力
- `js/result.js`: 予算・好み・FC・期限・サブスクの分岐
- `data/config.json`: 商品、価格、締切、リンク、質問選択肢
- `data/messages.json`: 案内文のパーツ

## 実装済み

- 店舗の有無→店舗がない/不明の場合のみセブンの有無→FC→複数選択サブスク→予算→1,800〜7,000円の場合のみ好み
- 予算8段階（0/300/1400/1800/3600/5000/7000/それ以上）
- FC限定盤の提案と「わちゃわちゃ」は、FC会員かつ2026-12-21までのときのみ
- 3,600円は第一候補に好みを反映し、購入可能な他の1枚を第二候補として列挙
- 5,000円は3形態セットを優先して、追加1,800円でFC盤を提案
- 7,000円は3形態＋デジタル、条件付きでFC盤、好みに応じた追加購入提案
- 対象店舗が不明なら店頭/通販のアコーディオン表示
- 音楽サブスクの案内、Stationhead、U-NEXT、YouTube、SNS、ラジオ/推し活リクエスト
- localStorageの途中回答・完成結果を別管理。再診断が完了するまで前回の結果を保持
- 結果のPNG画像化。対応端末は共有シート、その他はダウンロード

## 公開前の設定

1. `data/config.json` の `links.storeList` に許諾済みの店舗一覧URLを設定してください（未設定時は案内のみ表示）。
2. `links.fc` にFC限定盤の正式な購入先を設定してください。
3. 新曲の価格・収録内容、FC限定盤の予約期限、通販の店舗受取・フラゲ条件、U-NEXTでのリクエスト可能回数を公式情報と照合してください。
4. GitHub PagesでHTTPS公開し、iOS SafariとAndroid Chromeで途中再開、結果上書き、画像保存を確認してください。

画像化にはボタン操作時のみjsDelivr上の `html-to-image` を使用します。オフラインでPNGを生成する場合はライブラリをリポジトリへローカル配置してください。

保存データはこのブラウザ・このオリジンのみに保持されます。ブラウザデータを削除した場合や端末・ブラウザが異なる場合には引き継がれません。外部サイトへの送信や分析機能はありません。

## 注意

非公式のファンツールです。集計対象店、売上計上日、販売条件、専用特典の付与条件は変動します。CDを発売週日曜までに受け取った場合でも、必ず初週売上に算入されると保証するものではありません。
